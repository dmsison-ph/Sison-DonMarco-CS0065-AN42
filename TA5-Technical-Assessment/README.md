# Technical Assessment 5: Sentiment Analysis

This project uses Python, TextBlob, and NLTK to analyze sentence sentiment and count happy and sad words.

## Files

- `TA5_Sison.py` - analyzes 10 sentences and summarizes their sentiments
- `challenge.py` - counts happy and sad words using the NLTK Opinion Lexicon
- `TA5_Sison.pdf` - completed activity sheet

## How to Run

1. Install TextBlob: `py -m pip install textblob`
2. Run `py TA5_Sison.py`
3. Run `py challenge.py`
