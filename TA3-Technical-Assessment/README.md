# Technical Assessment 3: Case-Based Reasoning System Development

This repository contains the required outputs for Technical Assessment 3. The project uses Python to create a Case-Based Reasoning system for an Intelligent Tutoring System. It compares a new student problem with previous cases, retrieves the most similar case, adapts its tutoring solution, and retains the newly solved case.

## Files

- `TA3_Sison_Millan.py` - Python program for the Case-Based Reasoning system
- `TA3_Sison_Millan.pdf` - technical assessment documentation, source code, outputs, screenshots, and pair reflection

## How to Run

1. Install Python 3 on your computer.
2. Open a terminal inside the project folder.
3. Run the program using:

   `python TA3_Sison_Millan.py`
4. Review the similarity scores calculated for the previous tutoring cases.
5. Observe the retrieved case, adapted tutoring solution, and updated case base displayed in the terminal.
