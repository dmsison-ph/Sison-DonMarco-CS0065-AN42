# Technical Assessment 4: Knowledge Representation, RBR, and CBR

This repository contains the required outputs for Technical Assessment 4. The project uses Python to demonstrate Knowledge Representation, Rule-Based Reasoning, and Case-Based Reasoning through a weather-based outdoor activity recommendation system. It evaluates weather facts using IF-THEN rules and compares the current situation with previous cases to recommend an appropriate action.

## Files

- `TA4_Sison.py` - Python program for the Knowledge Representation, Rule-Based Reasoning, and Case-Based Reasoning system
- `TA4_Sison.pdf` - technical assessment documentation, source code, outputs, screenshots, and reflection

## How to Run

1. Install Python 3 on your computer.
2. Open a terminal inside the project folder.
3. Run the program using:

   `python TA4_Sison.py`
4. Review the weather facts, rule-based recommendations, and case similarity scores displayed in the terminal.
5. Choose whether to keep the suggested solution, use the provided revised solution, or enter your own solution.
6. Observe the final recommendation and updated case base.
