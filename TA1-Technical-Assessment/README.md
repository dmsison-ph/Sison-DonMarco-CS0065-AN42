# Technical Assessment 1: Random Walk Simulation Using AgentPy

This repository contains the required outputs for Technical Assessment 1. The project uses Python and AgentPy to simulate multiple agents moving randomly within a bounded grid. It tracks each agent's path, displays an animated visualization, and analyzes the agents' final positions.

## Files

- `TA1_Sison.py` - Python program for the random walk simulation
- `TA1_Sison.pdf` - technical assessment documentation, source code, outputs, observations, and answers

## How to Run

1. Install Python 3 on your computer.
2. Install the required libraries by running:

   `pip install agentpy matplotlib`

3. Open a terminal inside the project folder.
4. Run the program using:

   `python TA1_Sison.py`

5. Enter the requested number of agents, grid size, and simulation steps.
6. Observe the animated agent movement and close the animation window to view the recorded paths and final-position analysis in the terminal.
