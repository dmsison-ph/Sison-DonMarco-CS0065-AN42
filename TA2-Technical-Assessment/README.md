# Technical Assessment 2 Rule-Based Vacuum Agent

This repository contains the required outputs for Technical Assessment 2. The project uses Python to implement a rule-based vacuum agent that observes whether a room is dirty or clean. The agent cleans a dirty room or moves to the other room when its current location is already clean.

## Files

- `TA2_Sison.py` - Python program for the rule-based vacuum agent
- `TA2_Sison.pdf` - technical assessment documentation, source code, outputs, observations, and answers

## How to Run

1. Install Python 3 on your computer.
2. Open a terminal inside the project folder.
3. Run the program using

   `python TA2_Sison.py`

4. Enter `dirty` or `clean` when asked for the initial state of rooms A and B.
5. Enter the number of steps for the simulation.
6. Review the agent's location, action, and updated room states after every step.
